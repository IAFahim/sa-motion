## Real findings fixed in the fixtures (kernels untouched)

- Kyle's Ribs is a sibling of its Hip, not a descendant: `RetargetTable.Compile`
  rig→canonical returns `InvalidTable` for the name-mapped table. Asserted as a
  documented topology fact (`KyleReverseTableRejectedForSiblingSpine`); Kyle is a
  retarget TARGET only, UAL rigs source both directions. A Hips→Root remap would
  compile but changes the anatomical judgment, so it stays out.
- `TwoBoneIK.Solve` returns a COMPOSED lower delta (`LowerDelta = lower*upper`, world
  frame): applying it needs `P_new⁻¹·D·W_old`, not `P_new⁻¹·D·P_new·L`. Probed exact
  to 1e-7 over 200 random chains. Any future Unity IK adapter must use this form.
- The travel-test expected point double-subtracted the root translation
  (`R⁻¹(W−P) + T⁻¹`); hold error equalled `|rootWorld.Position|` exactly. Removed.
- Loop clips wrap `t==Duration` to frame 0 on `Sample`; the sweep compares the
  endpoint against frame 0 (C08 already established the wrap).
- Calibration must use a standing frame (T-pose preferred, Idle fallback): the
  manifest-first clip was a crouch (hip 0.69 vs true 0.92). Hip height is now
  `(hipY − minAnkleY)/0.9`, bind-independent.
- Sole contact must be bind-relative (`R_bind⁻¹·offset`), not live-rotated family
  offset: UAL foot binds point forward, which swung the contact 19 cm high in T-pose.
  Per-foot `SoleLocal` is calibrated from the reference pose.
- Stance = first-half stationary contact (min ankle speed near the clip floor), not
  most-bent knee (swing bend exceeds stance bend) and not lowest ankle (swing
  dorsiflexion). Planting late makes release unobservable.
- The synthetic slope plane is anchored at the clip floor contact; tilt is still
  exercised through Walkable classification and sole alignment.

## C12 live verification (fresh session, staged CF1 DLLs, then fully reverted)

- Subscene bake works end to end on real UAL1 data: rigs=1, timelines=1, 66 bones,
  2 render meshes, 0 console errors/warnings. Baker `Bake()` on the 67-bone rig and
  both clips verified live (encode + table + calibration all green in-worker).
- Interrupt walk→idle (`PlaySingle`): boundary 0.93° including one frame of natural
  walk (max natural step 32.9°); the strict same-time gate (<=0.05°) stays in
  EditMode (`SharedFamilyTests`). Seek to 1.5 s: deterministic 4.4° jump (stateless
  by design). Scales exactly 1.0 everywhere.
- SA.Tests 63/63 on the C12 branch with staged DLLs (6/6 SharedFamilyTests). The only
  red anywhere is the documented `PackedDllMatchesTheDotNetPackage` golden, which
  must fail while fresh DLLs are staged and passes after the integrator pack.
- What the live run taught (all fixed on `packet/C12-ecs` or in the scratch setup):
  plain scenes do not bake here — use a host + SubScene; run Convert Skinned Mesh
  Renderers only after RigAuthoring exists (it no-ops otherwise, and the baker then
  correctly rejects the unconverted mesh holder instead of baking a bad table);
  the name scorer needed UAL/Kyle conventions (side veto, spine_01/02/03 split,
  pelvis/thigh/calf/foot/ball aliases, finger level digits) plus regression pins.
- The old `eng/unity.sh eval`-style pause helper
  (`GetExistingSystemManaged<UpdateWorldTimeSystem>`) does not resolve in eval;
  match the system by name and disable it, or the hand-stepped clock is overwritten.
- Scratch (`Assets/_Scratch_/C12`, temp setup script, CSVs) deleted; bridge DLLs and
  `.meta` files restored byte-identical (`git status` clean in sa-motion); package
  checkout left on green `packet/C11-authoring-window`.
