## Real findings fixed in the fixtures (kernels untouched)

- Kyle's Ribs is a sibling of its Hip, not a descendant: `RetargetTable.Compile`
  rig→canonical returns `InvalidTable` for the name-mapped table. Asserted as a
  documented topology fact (`KyleReverseTableRejectedForSiblingSpine`); Kyle is a
  retarget TARGET only, UAL rigs source both directions. A Hips→Root remap would
  compile but changes the anatomical judgment, so it stays out.
- `TwoBoneIK.Solve` returns a COMPOSED lower delta (`LowerDelta = lower*upper`, world
  frame): applying it needs `P_new⁻¹·D·W_old`, not `P_new⁻¹·D·P_new·L`. Probed exact
  to 1e-7 over 200 random chains. Any future Unity IK adapter must use this form.
- The travel-test expected point double-subtracted the root translation
  (`R⁻¹(W−P) + T⁻¹`); hold error equalled `|rootWorld.Position|` exactly. Removed.
- Loop clips wrap `t==Duration` to frame 0 on `Sample`; the sweep compares the
  endpoint against frame 0 (C08 already established the wrap).
- Calibration must use a standing frame (T-pose preferred, Idle fallback): the
  manifest-first clip was a crouch (hip 0.69 vs true 0.92). Hip height is now
  `(hipY − minAnkleY)/0.9`, bind-independent.
- Sole contact must be bind-relative (`R_bind⁻¹·offset`), not live-rotated family
  offset: UAL foot binds point forward, which swung the contact 19 cm high in T-pose.
  Per-foot `SoleLocal` is calibrated from the reference pose.
- Stance = first-half stationary contact (min ankle speed near the clip floor), not
  most-bent knee (swing bend exceeds stance bend) and not lowest ankle (swing
  dorsiflexion). Planting late makes release unobservable.
- The synthetic slope plane is anchored at the clip floor contact; tilt is still
  exercised through Walkable classification and sole alignment.
