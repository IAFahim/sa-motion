# N7 handoff: contract review of the inertialization kernel

## What was built

Reviewed plan.md sections 10.1/10.2 (lines 382-437) against `src/SA.Motion/Inertialization/*`
(`ScalarDecay.cs`, `PoseTransition.cs`) and `tests/SA.Motion.Tests/InertializationTests.cs`.
Added `tests/SA.Motion.Tests/ContractTests.cs` with 19 clause-named tests covering every 10.2
requirement that had no existing test. Edited nothing under `src/`. No open gaps: every new
test passes, so no `[Fact(Skip=...)]` markers were needed.

Scale policy is documented as an SA extension, not attributed to the slides. The C# kernel is
the only implementation in this repo: there is no HLSL mirror, no contact/IK stage, and no
physical-body policy under `src/`, so those clauses are recorded as out of scope here.
