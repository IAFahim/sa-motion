# Handoff N5: Independent humanoid profile

## Done
Implemented the N5 packet on branch packet/N5. New files only:
`src/SA.Humanoid/Profile/JointLimit.cs`, `RoleSpec.cs`, `HumanProfile.cs`;
`tests/SA.Humanoid.Tests/Profile/ProfileTests.cs`; `docs/profile.md` (38 lines).
`Roles.cs` and all other files untouched.

Design: mass fractions are de Leva 1996 Table 2 male means regrouped onto the
15 SA roles (Pelvis = lower trunk, Torso = upper + middle trunk); every limit,
density weight (uniform 1.0) and the 0.05 rad hinge bound are authored starting
values, marked (P)/(A) in docs/profile.md. Hinge flexion (elbows, knees) runs
on the twist axis with swings pinned <= 0.05; L/R twist ranges are exact
negations, swings shared. `Of` switches over all roles with a default arm for
undefined values; `Mass` returns 0 for non-finite or non-positive totals.
