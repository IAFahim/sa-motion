# Handoff R6: effectors, soft limits and drive conversion

Done. `Drive/*` converts mid-relative (twist, lean1, lean2) effector values plus
strength/damping into `JointDrive` inputs for the existing `QuaternionDrive.Torque`
step, with soft-limit/gain policy and the shortest-arc tracking error.

## Added

- `src/SA.ReactionControl/Drive/DriveParams.cs`: `EffectorAngles`, `DriveLimits`,
  `DriveParams` with `Standard` (strength 12 1/s^2, damping 2 1/s, max torque
  200 N m, min damping 0.05 1/s, stiffness cap 1000 1/s^2, limit margin 0.02 rad,
  soft pull 0.25).
- `src/SA.ReactionControl/Drive/SoftLimit.cs`: `SoftLimit` + `Accel` (direct
  translation of `SoftLimit::accel`), `SoftBounds` triple (default is disabled).
- `src/SA.ReactionControl/Drive/Drive.cs`: `ToJointDrive` (two overloads),
  `Gains`, `ClampToLimits`, `PullToSoftLimit`, `FromAngles`, `ToAngles`,
  `TrackingError` (via `RotationError.Between`).
- `tests/SA.ReactionControl.Tests/Drive/DriveTests.cs`: 9 tests covering every
  Check bullet plus hostile inputs.
- `docs/port/R6.md`: port record, written and committed before code.

## Decisions

- Twist-swing decomposition (`FromAngles`/`ToAngles`) is ADAPTED standard
  mechanics replacing the tan-quaternion form; kv-scaled math constants unused.
- `targets` lean-radius scaling is ADAPTED to a unit-ellipse projection plus a
  per-axis margin clamp; kv-scaled radius unused.
- Solver-frame projection (`swing3`, `sdot`, `solve3`) and implicit-Euler muscle
  integration are excluded: Unity Physics stays the sole product solver.
- No part indexing in R6, so the 21-part to 15-role collapse is not applicable.
- No unresolved opaque fields kept; `oppose_gravity`/`injury`/blending belong
  to R1/R7.
