# N2 handoff: frames and inertia conversions

## What was built

`src/SA.Motion/Mechanics/` (new directory, namespace `SA.Motion.Mechanics`):

- `Frame.cs`: `Frame` struct (`Float3 Position`, `Quaternion Rotation`, `static Identity`)
  plus `enum Axis : byte { X, Y, Z }`.
- `Frames.cs`: `Compose` (position `outer.Position + Rotate(outer.R, inner.Position)`,
  rotation `Normalize(outer.R * inner.R)`), `Inverse` (`InverseUnit` plus
  `-Rotate(inv, p)`), `Relative` (`Compose(Inverse(parent), child)`),
  `TransformPoint` (rotate then translate), `TransformDirection` (rotate only),
  `Mirror` (negate position component on the axis; rotation
  `(x,-y,-z,w)` / `(-x,y,-z,w)` / `(-x,-y,z,w)` for X / Y / Z, which is the
  conjugation `M*R*M` of a proper rotation by the axis reflection, so the
  result stays a proper rotation and `Mirror(Mirror(f)) == f`).
- `Float3x3.cs`: column-major `C0, C1, C2`, `Identity`, `Multiply(v)` as
  `C0*v.X + C1*v.Y + C2*v.Z`, `Transpose`.
- `Inertia.cs`: `ToWorld` computes `R*diag(principal)*R^T` via scaled columns
  combined with the basis rows; `InverseToWorld` uses the same sandwich with
  per-component inverse (`principal <= 1e-6` or non-finite gives `0`).

Totality: non-finite or near-zero-length rotation sanitizes to identity,
non-finite position/point/direction sanitizes to zero, non-finite principal
sanitizes to zero in `ToWorld`, negative principals stay as-is in `ToWorld`
(still symmetric with exact trace) and map to zero inverse in
`InverseToWorld`. No code path throws.

`tests/SA.Motion.Tests/FramesTests.cs`, `InertiaTests.cs`: fixed-seed random
suites covering identity (`Compose(Inverse(f),f)` both orders, 200 frames),
`Relative` reconstruction, associativity, `TransformPoint` distribution over
composition, direction translation-invariance plus length preservation, mirror
commutation for all three axes plus double-mirror round trip, inertia symmetry
/ trace / `ToWorld*InverseToWorld == Identity` / axis-aligned reciprocals /
locked-axis annihilation (`inv * Rotate(q, basis) == 0`, also for negative and
`1e-7` principals), and degenerate inputs (NaN/Inf frames, default quaternion,
NaN/Inf/negative/zero principals all return finite values, zero quaternion
acts as identity rotation).

## Open questions / ambiguities (simplest reading taken)

- `TransformPoint`/`TransformDirection` with a non-finite point/direction
  argument treat that argument as zero (packet only pins down NaN frames).
- Non-finite principal in `ToWorld` maps to `0`; negative principals in
  `ToWorld` are kept (finite, symmetric, exact trace) rather than clamped.
- `Mirror` with an out-of-range `Axis` value falls through to the Z branch;
  total and never throws.
