# R3 handoff: BodyBalance loss-of-balance and catch-fall decisions

## What was built

Owns only: `src/SA.ReactionControl/BodyBalance/`, `tests/SA.ReactionControl.Tests/BodyBalance/`, `docs/port/R3.md`. Nothing else touched.

`src/SA.ReactionControl/BodyBalance/` (4 files, pure static + caller-owned POD state, no alloc/LINQ/reflection, ordinary float math):

- `BodyBalanceParams.cs`: 47-field struct with `Standard`. Every tuning slot in `nmbb.rs` maps to one named field (slot map in the port record); source-literal defaults stay literals. Nine packet-added fields for the decision layer (`DecisionLoseLean` 0.12, `DecisionFallLean` 0.6, `DecisionExitFraction` 0.5, `FallHoldTime` 0.8 s, `LookProbeRange`, `MaxDrive`, `UprightCorrect`, `TwistCorrect`, `TorsoPitchBias`, `LookVelLead`, use-flags).
- `BalanceTypes.cs`: `BalanceDecision` (`Recovering`/`LosingBalance`/`Falling`), `BalanceInput` (dt, stepping, failed/catching/grounded/contact flags, push/look targets), `BalanceOutput` (decision, head-look target/velocity/stiffness, spine-lean intent, lean response, turn intent, step clamp, catch-fall gains, stabiliser triple, step budget).
- `BodyBalanceState.cs`: timers, previous euler, own-frame basis, fixed-seed deterministic RNG, decision + hold timer. `Activate` takes torso/pelvis orientations.
- `BodyBalance.cs`: `Tick` over `ReadOnlySpan<RoleBody>` + `ReadOnlySpan<SupportProbe>` + input, writes `Span<JointDrive>` for Torso/Head/UpperArm/Forearm/Hand roles. Ports `tick` (step-change cut/clamp, head-look with velocity lead, probabilistic body-turn, spine lean from tilt/rate excess with the returning-to-balance factor, hip-coupled arm drives, elbow bend timer, authority blend, stabiliser/catch-fall outputs), `look_at` (probe-first, then look target, then push source), `frame`/`angles` (Y-up analogue; `sdot` verified to be a plain dot product), own-frame helpers. Failed input latches `Falling` with catch-fall gains; non-finite or wrong-length input gives passive drives + `Falling` and never throws.

`tests/SA.ReactionControl.Tests/BodyBalance/BodyBalanceTests.cs` (10 tests): small push stays `Recovering` with bounded response; large push falls and holds through the hold window without flicker then recovers; metric-only large tilt falls without the failed flag; head-look points at the push source (0 deg, tolerance 2 deg) and prefers the nearest probe; bit-identical determinism across two states; hysteresis at the lean threshold (0.5 → 0.4 stays `LosingBalance`, 0.2 recovers) and at the fall threshold with hold timing; hostile NaN/Inf/huge/negative-dt inputs give finite passive bounded output; wrong span lengths fall without throwing.

Adapted (standard-mechanics replacements, all in the port record): `Effector.desired` euler triples become corrective local rotations on current orientations; `set_stiffness` strength/damping convention carried into `JointDrive`; kinetic speed, com, hip desired/actual, busy flags, RNG, obstacle find, stabiliser, touch bitmask all mapped to role/probe/input equivalents. Excluded: `from_own`/`inst_place`/`to_own`, `deactivate`, `head_look_pos`/`head_look_instance_index` params (per-event inputs instead). No opaque fields. World up is +Y.
