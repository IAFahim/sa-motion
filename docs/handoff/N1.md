# N1 handoff: finished transitions return the destination without the polynomial

## What was built

`src/SA.Motion/Inertialization/PoseTransition.cs` only, plus the new test file:

- `VectorOffset.Apply`: when `Decay.Duration <= Scalar.DurationEpsilon` or `elapsed >= Decay.Duration`, returns `destination` directly instead of evaluating `destination + Direction * Decay.Evaluate(elapsed).Value`.
- `RotationOffset.Apply`: same finished condition returns `Quaternion.Normalize(destination)` instead of `Normalize(Multiply(AxisAngle(Axis, Evaluate(elapsed).Value), Normalize(destination)))`. Normalizing the destination is exactly what the full formula yields for a finished decay (`Evaluate` returns a zero sample, `AxisAngle(axis, 0)` is identity, `Multiply(identity, Normalize(d))` is `Normalize(d)`).
- `PoseTransition.Apply`: same signature. Position and rotation delegate to the channel early-outs above. Scale takes the old `Exp(Log)` roundtrip only when the destination scale is positive, a correction exists (`Decay.Duration > 0f`, unchanged threshold), and the log-scale channel is not finished; otherwise it returns `destination.Scale` exactly, which also removes the `Log`/`Exp` cost on finished transitions and makes a fully finished `Apply` return the destination pose exactly (position, normalized rotation, scale).
- Unfinished paths run the old expressions verbatim, so unfinished results are bit-identical.
- Struct fields and layouts unchanged; no signature changes.

`tests/SA.Motion.Tests/TransitionEarlyOutTests.cs` (new, 5 tests):

- Old-expression references inside the test file for both channels.
- 200 deterministic random offsets per channel (`Random(4177)` vectors, `Random(9021)` rotations) swept over a grid from -1 to `2 * Duration`, plus `elapsed == Duration` exactly, two points past `Duration`, and `NaN` elapsed, compared within 1e-6.
- Cleared (`default`) offsets swept the same way.
- `PoseTransition.Apply` on a finished transition (elapsed equal to and past the longest channel duration, with a non-unit destination rotation to exercise normalization) and on an empty-history transition both return the destination pose exactly per component.
