## Assertions

Every fuzz iteration asserts no exception escapes. Every written `JointDrive` has
finite target, target angular velocity, stiffness, damping, and max torque, with
stiffness, damping, and max torque not negative. Float and `Float3` reports are
asserted finite component by component. Sums are never asserted because two
finite extremes overflow to infinity and would fail the check without any source
defect. Two assertions are conditional, each tied one to one to a pinned gap
below: `feet.Centre` is asserted only when `snapshot.Com` is finite, and
`LeanAngles` output is asserted only when its `fy`/`fz` inputs are finite.

## Open gaps

Two failures were found. Per the packet, each is pinned as a skipped test with
the exact input, actual output, and expected output recorded here. `src/` was
not edited.

### Gap 1: `BalanceOverflowCom_OpenGap` (skipped)

Root: `SnapshotBuilder.TryBuild` accumulates `com += body.Position * weight`
without clamping, so overflow-magnitude inputs produce a non-finite COM while
returning true. Symptom: `FootPlacement.Update` copies it into `feet.Centre`
on the stepping path.

- Input: 15 bodies from `Fuzz.Body(6 * 17 + b * 37, 6 + b)`, probes
  `Fuzz.Probe(78, 6)` and `Fuzz.Probe(114, 7)`, params `BalanceParams.Standard`
  with `Up = Fuzz.Vec(6)` and `StepClamp = 0.6`, feet seeded with
  `FootLeft = Fuzz.Vec(42)`, `FootRight = Fuzz.Vec(66)`,
  `Centre = Fuzz.Vec(138)`, then `Decide` plus `Update`.
- Actual: `TryBuild` returns true with
  `snapshot.Com = (inf, -inf, 2.4799552E+28)`; `SteppingLeg = 1`;
  `feet.Centre = (NaN, NaN, -inf)`. Reproduced 4166 of 20000 palette
  combinations. `BalanceSolve.Solve` drives stayed finite in all 20000 cases.
- Expected: `feet.Centre` finite. The file already clamps through
  `BalanceMath.Sanitize` everywhere else, so clamping positions before weighting
  in `TryBuild` is the consistent fix. Owned by the R2 area, not T1.

### Gap 2: `LeanAnglesNaN_OpenGap` (skipped)

- Input: `BodyBalance.LeanAngles` with `fx = (0, 0, 0)`, `fy = (0, NaN, 0)`,
  `fz = (0, 0, 1)`.
- Actual: `(NaN, 0, -1.5707964)`. `AsinClamped` passes NaN to `Math.Asin`,
  and the `1/guard` path propagates it.
- Expected: a finite default. `BodyBalance.Tick` is unaffected because its
  `InputsFinite` guard rejects NaN bodies before reaching this helper.

## Test design notes

- `PelvisControl.Update` never writes `BlendVelocity`, `Centre`, or `Lift`, and
  `FootPlacement.Decide` copies the seeded `FootLeft` into `Start`, so those
  fields are not asserted: they would check the test seeds, not source output.
- `Fuzz.Drives` requires the drives span to match the bodies span length.
- Spans of the wrong length (0, 14, 16, 64 bodies; short and empty drives;
  empty and oversized request, clip, and probe lists) are exercised for every
  span-taking entry and return passive or default without throwing.
