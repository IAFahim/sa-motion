# N3 handoff: bounded quaternion drive

## What was built
- `src/SA.Motion/Mechanics/DriveGains.cs`: plain `StructLayout.Sequential` struct with `Stiffness`, `Damping`, `MaxTorque` floats.
- `src/SA.Motion/Mechanics/QuaternionDrive.cs`: static class with total function `Torque(current, target, angularVelocity, targetAngularVelocity, gains)`. Normalizes both quaternions first (zero quaternion falls back to identity via `Quaternion.Normalize`), forms world-frame error `e = target * inverse(current)` flipped to `w >= 0`, builds the rotation vector `r = axis * angle` with `angle = 2 * atan2(|v|, w)` and the `r = 2v` shortcut for `|v| < 1e-6`, returns `Stiffness * r + Damping * (targetAngularVelocity - angularVelocity)` scaled down to `MaxTorque` when over the cap. Any non-finite input quaternion component or velocity, any non-finite gain, any negative stiffness/damping, `MaxTorque <= 0`, or a non-finite computed torque yields zero torque.
- `tests/SA.Motion.Tests/QuaternionDriveTests.cs`: covers double-cover equivalence, zero error with matching velocities, swap negation, cap magnitude plus direction preservation, zero gains, bad-gain and non-finite-input totality theories, non-unit normalization equivalence, zero-quaternion-as-identity, tiny-step-along-torque shrinking the error angle, and the test-only rigid rotor (isotropic `I = 2`, semi-implicit Euler, world-frame `delta * q` update) for all six uncapped `(startAngle, dt)` combos plus the capped `MaxTorque = 20` convergence case.

## Derivation (kept out of code per packet)
Standard rotational PD control on SO(3): the world-frame error `e = target * inverse(current)` is the rotation that takes current to target; its rotation vector `r = axis * angle` is the proportional term, pointing along the axis that reduces the error with magnitude equal to the remaining angle, so `Stiffness * r` is a restoring torque. Flipping to `w >= 0` picks the shortest path since `q` and `-q` encode the same rotation. The derivative term damps world-frame angular-velocity error `targetAngularVelocity - angularVelocity`. For `|v| < 1e-6` the small-angle linearization `r = 2v` avoids dividing by a near-zero length (it matches the first-order expansion of `2 * atan2(|v|, w) * v / |v|` at `w ~ 1`). Capping by rescaling preserves torque direction so the drive never pushes the wrong way under saturation. Critical damping `D = 2 * sqrt(S * I)` used in the rotor tests is the linear-regime value for a second-order system `I * angle'' + D * angle' + S * angle = 0`.
