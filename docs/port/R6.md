## Excluded or adapted

- `Character`, `Effector`, `JointDef`, masks, `lock`/`unlock`, `blend_to_zero`, `set_relaxation`, `pose`, `incoming_*`, asset/layout parsing (`nmrs.rs` before line 396): asset and game-file machinery, excluded.
- `loose()` limit widening and the `LOOSE` flag: depend on game asset state, excluded; limits pass through unchanged.
- `oppose_gravity`, `injury`/`well`, `muscle_stiffness` blend, `one`/`zero`: gravity compensation, damage and blend ownership belong to other packets (R1/R7); excluded, no unresolved opaque fields kept.
- Solver-frame projection (`swing3`, `sdot`, `solve3`, `answer`, `pair`, hinge-axis solve): native-solver internals, excluded; Unity Physics stays the sole product solver.
- Part indexing: R6 math is joint-local with no part indexing, so the 21-part to 15-role collapse is not applicable; callers index by `Role`.
- `q`/`-q` double cover: `FromAngles` emits `Quaternion.Canonical` targets and `TrackingError` canonicalizes first, so both covers give the same drive.
