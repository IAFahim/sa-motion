# N13: Soft joint limits as a corrective drive

Owns: `src/SA.Motion/Mechanics/SoftLimits.cs`, `tests/SA.Motion.Tests/SoftLimitsTests.cs`, `docs/softlimits.md`. Edit nothing else. This is independent MIT code: derive it from standard mechanics, do not read Delirium.

## Why

Unity's cone-and-twist ragdoll joint limits exploded under a hard knockdown, so characters currently use ball-and-socket joints with no limits. A soft limit applied as a corrective drive restores the limits without a solver constraint.

## API (namespace `SA.Motion.Mechanics`, uses `SA.Motion.Numerics`)

```text
readonly struct ConeTwistLimit { float ConeAngle; float TwistMin; float TwistMax; }
readonly struct HingeLimit { float Min; float Max; }
readonly struct LimitGains { float Stiffness; float Damping; float MaxTorque; }
static class SoftLimits {
  Float3 ConeTwistTorque(Quaternion relative, Quaternion rest, Float3 limbAxis, Float3 relativeAngularVelocity, in ConeTwistLimit limit, in LimitGains gains)
  Float3 HingeTorque(Quaternion relative, Quaternion rest, Float3 hingeAxis, Float3 relativeAngularVelocity, in HingeLimit limit, in LimitGains gains)
}
```

`relative` is the child rotation in the parent frame. The result is a torque on the child (negate for the parent), zero while inside the limits, growing with the violation beyond them: `Stiffness * excess` plus damping only while moving further outside, capped at `MaxTorque`.

## Check

- Inside the limits: exactly zero, for many random poses.
- Outside: the torque points back toward the allowed region (dot with the violation direction is positive) and its magnitude grows monotonically with the excess up to the cap.
- Continuity: torque is zero at the boundary and has no jump (compare values at excess 0 and 1e-4).
- Damping acts only while the angular velocity increases the violation.
- `q` and `-q` give the same torque. Limits around 0 and around pi, hostile inputs (NaN, infinity, zero-length quaternions) give zero torque and no exception.
- Integration: a rotor test like the one in `QuaternionDriveTests` pushed past a limit with these gains settles back within the limit without oscillating beyond 5 percent of the excess.
