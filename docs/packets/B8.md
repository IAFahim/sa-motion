# B8: Angular momentum and arm swing

Read `docs/packets/B-common.md` first, then this file. Project name: `SA.Balance.Momentum`.

Use the hip strategy and the arms as flywheels: counter-rotate the torso and swing the arms to regulate whole-body angular momentum against forward and sideways pushes (Pratt et al. 2006; Hofmann 2006), on top of the hold. Report how much push the arms and torso add over the hold with the arms frozen.
