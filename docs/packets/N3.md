## API (exact names)

```text
struct DriveGains { float Stiffness; float Damping; float MaxTorque }
static class QuaternionDrive {
  Float3 Torque(Quaternion current, Quaternion target, Float3 angularVelocity, Float3 targetAngularVelocity, DriveGains gains)
}
```

## Definition

- Error rotation in world frame: `e = target * inverse(current)`, flipped to `w >= 0` (shortest path). Rotation vector `r = axis * angle`, `angle = 2 * atan2(|v|, w)`. For `|v|` below 1e-6 use `r = 2 * v`.
- `torque = Stiffness * r + Damping * (targetAngularVelocity - angularVelocity)`.
- If `|torque| > MaxTorque`, scale it down to `MaxTorque` and keep its direction.
- Total: any non-finite input, a non-finite or negative gain, or `MaxTorque <= 0` returns zero torque. Non-unit quaternions are normalized first; a zero quaternion counts as identity.

## Tests

- `target` and `-target` give the same torque. Zero error and matching velocities give zero torque.
- Swapping current and target negates the position term.
- The cap holds and direction is preserved. Gains of zero give zero.
- Applying a tiny rotation about the returned torque direction to `current` reduces the angle to `target`.
- Test-only rigid rotor inside the test file: isotropic inertia `I = 2`, semi-implicit Euler (`w += torque / I * dt`, then rotate `q` by `w * dt`). With `Stiffness = 100`, `Damping = 2 * sqrt(Stiffness * I)`, no cap, `dt` of 1/60 and 1/240, start angles 0.1, 1.0 and 3.0 rad: the angle never grows beyond 1% of the start angle above the minimum already reached, and ends below 1e-3 rad within 5 s.
- With `MaxTorque = 20` and a start angle of 3.0 rad it still converges below 1e-3 rad within 10 s.
