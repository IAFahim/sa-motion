# B9: Linear policy search

Read `docs/packets/B-common.md` first, then this file. Project name: `SA.Balance.Policy`.

A small linear feedback policy from `(com offset, com velocity, torso lean, torso angular velocity)` in the pelvis frame to target adjustments for each leg and torso joint, plus a step trigger on capture point distance. Fit the coefficients by evolution strategies against `Evaluator.RunFast` (deterministic seed, your own optimizer). Commit the coefficients with the optimization log, then evaluate with the full `Evaluator.Run`.
