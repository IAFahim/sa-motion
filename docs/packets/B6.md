# B6: Automatic tuner for the hold controller

Read `docs/packets/B-common.md` first, then this file. Project name: `SA.Balance.Tuned`.

Make the pose hold controller fully parametric (per-role stiffness, damping, torque cap, height servo gain, plus a COM-to-ankle gain) and write an optimizer in your test project (CMA-ES or a simple evolution strategy, written by you, deterministic seed) that maximizes `Evaluator.RunFast`. Run it for the whole time budget and keep the best parameters, then evaluate with the full `Evaluator.Run`. Commit the parameters as named constants with the optimization log.
