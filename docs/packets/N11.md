## API (exact names, namespace `SA.Humanoid.Build`)

```text
readonly struct BodyLayout { Role Role; Frame WorldFromBody; Float3 CapsuleStart; Float3 CapsuleEnd; float Radius; Float3 BoxHalfExtents; float Mass; Float3 CenterOfMass }
readonly struct JointLayout { Role Child; Role Parent; Float3 AnchorInParent; Float3 AnchorInChild; Quaternion JointFrameInParent; Quaternion JointFrameInChild; Quaternion RestRelative; JointLimit Limit }
readonly struct RagdollLayout { BodyLayout[] Bodies; JointLayout[] Joints; Diagnostic[] Diagnostics; bool IsValid }
static class RagdollBuilder { RagdollLayout Build(SkeletonBone[] skeleton, int[] boneOfRole, float totalMass) }
```

`Frame` is `SA.Motion.Mechanics.Frame`. `SkeletonBone`, `Diagnostic` and the role map come from `SA.Humanoid.Mapping` (packet N4). `JointLimit` and masses come from `SA.Humanoid.Profile` (N5). `Bodies` has `Roles.Count` entries indexed by role. `Joints` has `Roles.Count - 1` entries, one per non-root role.

## Rules

- World rest poses come from composing `SkeletonBone.Rest` down the parent chain. Reject non-uniform or non-positive scale with a diagnostic.
- Body origin is the role's joint position. The body x axis points along the bone toward the next role's joint. For leaf roles (head, hands, feet) continue the parent segment direction. Pelvis and torso are boxes; limbs, head, hands and feet are capsules. Radii are `BuildParams.Standard` ratios of segment length; every ratio is a named, documented authored value.
- Mass is `HumanProfile.Mass(role, totalMass)`. The centre of mass is the capsule or box centre in body space.
- Each joint anchor is the child's joint position, expressed in the parent body frame and in the child body frame, so both name the same world point. Joint frames are the child body rotation, so the rest relative rotation is identity in joint frames; `RestRelative` is `inverse(parent body rotation) * child body rotation`, the neutral target for a drive.
- Total: bad input gives diagnostics and a layout with `IsValid` false, never an exception. Zero-length segments (under 1 mm) get a diagnostic.
- Pure, deterministic, no managed allocation beyond the returned arrays.

## Check

- A Kyle-shaped skeleton and a differently oriented generic skeleton both build a valid layout.
- Masses sum to `totalMass` within 1e-4. For every joint the parent and child anchors name the same world point within 1e-5.
- Limits equal the profile values. All outputs are finite.
- Mirroring the skeleton left to right mirrors the layout.
- Capsule endpoints lie on the bone segments they were fitted to, within 1e-5.
- A zero-length segment, a missing role and a non-uniform scale each produce the expected diagnostic.
