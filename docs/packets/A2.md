## Build
- Every command takes `Span<ClipState> states, ref int count` instead of a `DynamicBuffer`. The capacity is `states.Length`. Live states are `states[0..count)` and order is preserved exactly as in Unity (append at the end, remove by shifting).
- When a command must add a state and `count == states.Length`, replace the live state with the smallest `Weight * Fade`, choosing the lowest index on a tie. Document this rule in `docs/animation.md` (create it, short).
- Clip durations come in as `ReadOnlySpan<float> durations`, indexed by `ClipIndex.Value`. A missing or non-positive duration means rate 0, exactly like an invalid `ClipAsset` in Unity.
- Port `Play`, `CrossFade`, `Blend`, `Stop`, `Find`, `IsPlaying`, `NormalizedTime`, `HasFinished`, `Rate`, `SyncedRate`, `Step` and the private `Converge` and `Pick` with identical semantics.
- Add `Seek(Span<ClipState> states, int count, byte layer, ClipIndex clip, float phase)`: sets the phase of the state that `Find` returns, wrapped with `Phase.Wrapped` for that state's wrap, and returns whether it found one. Timelines use it to show an exact time.
- `TransitionIntent` (Request, Seconds, Elapsed, Pending) and `TransitionPlayback.Play`, `PlaySynced`, `Blend` with the same decisions as Unity (`Start`, `Keep`, `Misuse`), plus `Membership`.

## Tests (`PlaybackTests.cs`)
Port every pure playback and transition test (commands are idempotent, cross-fade every frame still converges, cross-fade back revives, restart creates a fresh state, stop removes after the fade and zero speed pauses, synced states share one phase under 1000 random commands, the same sequence is bit-identical, repeating a request keeps revision and phase, a new key cuts, key reuse is misuse, weight changes are not new transitions, the gait phase is preserved). Add: a full buffer evicts the weakest state, seek wraps by mode, and totality (NaN speed, weight and seconds never produce NaN state; an empty span never throws).
