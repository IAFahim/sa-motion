# L2: Leg profiles as plain text

Base: branch `packet/L1-legs`. Worktree: `/home/i/GitHub/sa-motion-wt/L2`, branch `packet/L2`.

## Why
Designers tune `LegParams` (`src/SA.Motion/Legs/LegParams.cs`). Profiles must survive leaving Unity, diff cleanly in version control, and load in any engine. `LegParamsSpec` already describes every field: name, group, unit, range and text.

## Owns (create only these, edit nothing else)
- `src/SA.Motion/Legs/LegProfileText.cs`
- `tests/SA.Motion.Tests/LegProfileTextTests.cs`

## Build
- `public static string Write(in LegParams p)`: one line per field in `LegParam` order, `Name = value`, with values formatted by `float.ToString("R", CultureInfo.InvariantCulture)`. Lines end with `\n` and nothing else is written.
- `public static LegParams Read(string text, in LegParams fallback, List<string> problems)`: start from `fallback`. For each line trim whitespace and skip empty lines. Split at the first `=`. Match the name exactly against `LegParamsSpec.Text(field).Name`. Parse with `float.TryParse(..., NumberStyles.Float, CultureInfo.InvariantCulture, ...)` and store through `LegParamsSpec.With`. Unknown names, malformed lines, duplicates and non-finite or out-of-range values (use `LegParamsSpec.Bounds`) add one message each to `problems` (line number and reason) and leave the previous value. Null text returns `fallback` with one problem. Never throw.
- This is tooling, not a per-frame kernel, so strings and lists are fine. No reflection, no LINQ.

## Tests
Round trip: `Read(Write(p))` equals `p` bit for bit for every preset and for 100 random in-range profiles (seeded). Unknown keys, bad numbers, duplicates, NaN, out-of-range values and `null` each give exactly one problem and keep the fallback. Reordered lines and CRLF line endings still read.
