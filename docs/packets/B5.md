# B5: SIMBICON-style stepping

Read `docs/packets/B-common.md` first, then this file. Project name: `SA.Balance.Simbicon`.

A finite state machine with a pose hold in standing and, when pushed, two-state stepping: swing-hip target `theta = theta0 + c_d * d + c_v * v` where `d` and `v` are the COM offset and velocity from the stance foot, with torso and swing-leg PD (Yin, Loken and van de Panne 2007). Tune the constants against the scoreboard.
