## Deliver

A scenario runner that makes controller evaluation a one-liner:

```text
delegate void ControllerStep(HarnessWorld world, float dt, Span<JointDrive> drives)
readonly struct PushSpec { Role Role; Float3 Direction; float Impulse; float AtSeconds; }
readonly struct ScenarioResult { bool Fell; float PeakPelvisDisplacement; float PeakTorsoLean; float RecoverySeconds; float MaxFootStep; int Steps; float FinalPelvisHeight; }
static class Scenarios {
  ScenarioResult Run(ControllerStep controller, in PushSpec push, float seconds)
  ScenarioResult[] Sweep(ControllerStep controller, ReadOnlySpan<float> impulses, int directions, float seconds)
}
```

`Fell` means pelvis below 0.5 m or torso more than 60 degrees from upright at the end. `RecoverySeconds` is the time after the push until pelvis height and lean stay within 0.1 m and 15 degrees. `Steps` counts distinct foot lifts of more than 0.05 m.

## Check

- A do-nothing controller (passive drives) falls for every push and for no push: report which, with numbers.
- A hold-the-pose controller (a strong static drive toward the start pose) recovers small pushes: report the boundary impulse.
- Results are deterministic, `Sweep` returns `impulses.Length * directions` results in a stable order, hostile input returns a result with `Fell = true` and finite fields.
- `docs/harness-scenarios.md` shows the sweep table for the two controllers above (under 60 lines).
