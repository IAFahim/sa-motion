# B3: Virtual model control

Read `docs/packets/B-common.md` first, then this file. Project name: `SA.Balance.VirtualModel`.

Pratt's virtual model control: compute a desired virtual force and torque at the pelvis (height spring, pitch and roll springs, COM-over-support spring) and convert it to stance leg joint torques with the leg Jacobian transpose; swing leg tracks a foot placement from the capture point. Express the torques as `BodyDrive` targets and torque caps.
