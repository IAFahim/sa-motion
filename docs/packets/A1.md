## Build
1. `PoseMath`: `Align`, `Nlerp`, `Lerp`, `Delta`, `Accumulate`, `Add(PoseSum, Pose, weight)`, `Mean(PoseSum)` with exactly the Unity semantics, over `SA.Motion.Numerics` types. `Affine(in Pose)` and `Mul(in Affine, in Affine)` where `Affine` is a column-major 3x4 (`C0`, `C1`, `C2`, `C3` as `Float3`), `StructLayout.Sequential`, 48 bytes.
2. `ClipSampling.At(ReadOnlySpan<Pose> samples, int boneCount, int bone, float frame)`: the Unity `Sampling.At` over a flat `[frame * boneCount + bone]` array. Total: empty or short spans, bad indices and non-finite frames return `Pose.Identity` or the nearest valid frame, never throw.
3. `PoseBlend`, a data-oriented evaluator that works one clip at a time over all bones, instead of one bone at a time over all clips:
   - `Override(Span<PoseSum> sums, ReadOnlySpan<Pose> samples, int frameCount, float frame, ReadOnlySpan<float> mask, float weight)` adds a weighted sample for every bone (`mask[b] * weight`, skipping zero weights).
   - `Resolve(Span<Pose> pose, ReadOnlySpan<PoseSum> sums)` does `pose[b] = Lerp(pose[b], Mean(sums[b]), min(1, sums[b].Weight))` where the weight is positive, then clears `sums`.
   - `Additive(Span<Pose> pose, ReadOnlySpan<Pose> samples, ReadOnlySpan<Pose> reference, int frameCount, float frame, ReadOnlySpan<float> mask, float weight)` does `Accumulate(pose[b], Delta(sample, reference[b]), mask[b] * weight)`.
   - `NextLayer(ReadOnlySpan<ClipState> states, int after)` returns the next layer above `after`, or -1.
   Spans of different lengths use the shortest. Nothing allocates.
4. `Hierarchy.Model(ReadOnlySpan<int> parents, ReadOnlySpan<Pose> local, Span<Affine> model)`: parents come before children; a parent index that is not smaller than the child, or is out of range, makes the bone a root.

## Tests (`PoseTests.cs`)
- Port every pose-algebra and sampling test from `CoreTests.cs`: lerp endpoints, accumulate-a-delta recovers the pose, the mean of one ignores the quaternion sign, affine matches `System.Numerics.Matrix4x4` composition, sampling hits frames and interpolates.
- Parity: write a per-bone reference evaluator in the test file that copies `Evaluation.Bone` (layers ascending, override weighted mean, then additive deltas against the clip reference). On 200 random state lists (seeded `System.Random(7)`, 2 to 6 states, layers 0 to 2, both modes, random masks, 3 bones, 5 frames), `PoseBlend` driven layer by layer must match it within 1e-5 per component.
- Totality: NaN weights, frames and poses never throw and never produce NaN output.
- Hierarchy: a 3-bone chain matches hand-composed matrices, and a bad parent becomes a root.
