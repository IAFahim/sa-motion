## API (exact names)

```text
struct RequestState { uint Key; uint Membership; uint Revision; byte Active }
enum RequestDecision : byte { Start, Keep, Misuse }
static class TransitionRequests {
  RequestDecision Decide(RequestState current, uint desiredKey, uint membership, bool restart, out RequestState next)
}
```

`Key` identifies the destination recipe. `Membership` is a hash of the clips, mode and mask in that recipe. `Revision` counts starts.

## Rules

- Not active: `Start`, `next` is active with revision 1.
- Same key, same membership, no restart: `Keep`, `next` equals `current`.
- Same key, same membership, `restart` true: `Start`, revision plus one.
- Different key: `Start`, new key and membership, revision plus one.
- Same key, different membership: `Misuse`, `next` equals `current`.
- Revision wraps from `uint.MaxValue` to 1, never to 0.
- Total: every input combination returns a decision. `default(RequestState)` is the not-active state.
