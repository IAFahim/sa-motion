# N9: Totality fuzz of the existing kernels

Read `AGENTS.md` first, then this file. It is your whole task.

Owns: `tests/SA.Motion.Tests/TotalityTests.cs`, `docs/handoff/N9.md`. Edit nothing else, including `src/`.

Goal: prove the kernels are total functions: every input, including hostile floats, gives a defined output and never throws.

## Do

- Input palette for every float: 0, -0, NaN, +Inf, -Inf, `float.Epsilon`, `float.MaxValue`, `-float.MaxValue`, 1e-30, -1e-30, 1e30, -1e30, and ordinary values in -10 to 10. Use `new System.Random(12345)`.
- Cover: `ScalarDecay.Create` and `Evaluate`, `VectorOffset.Create` and `Apply`, `RotationOffset.Create` and `Apply`, `PoseHistory.Reset` and `Capture`, `PoseTransition.Create` and `Apply`, `Quaternion.Normalize`, `Canonical`, `AxisAngle`, `Multiply`, `InverseUnit`.
- Assert no exception. Where the inputs the function reads are all finite, assert every output float is finite. For `Apply` also assert the output is finite whenever the destination pose is finite and positive-scale.
- Run at least 200,000 combinations per function group, and keep the whole test class under 5 seconds.

## If a case fails

Do not edit `src/` and do not loosen the assertion. Mark the single failing test `[Fact(Skip = "OPEN GAP: <function and input class>")]`, and list in `docs/handoff/N9.md` the exact input, the actual output and the expected output, so the integrator can fix it. Main must stay green.

Commands: `eng/dotnet_test.sh`

## Conventions you must match

- `src/` projects: `netstandard2.1`, C# 9, block-scoped namespaces (no file-scoped namespaces, no records, no `required`), `Nullable` enabled, warnings are errors.
- `tests/` projects: `net10.0`, xunit, file-scoped namespaces, `Near(...)` style helpers as in `tests/SA.Motion.Tests/InertializationTests.cs`.
- Plain `[StructLayout(LayoutKind.Sequential)]` structs, `readonly` where possible, no managed allocation in anything under `src/SA.Motion`.
- No comments anywhere. `python3 eng/check_source_rules.py` must print `source rules: ok`.
- Tests are deterministic. A random generator uses a fixed seed.
