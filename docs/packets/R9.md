# R9: Assemble one reaction controller and tune it in the harness

Read `AGENTS.md` first, then `docs/packets/R-common.md`, then this file. They are your whole task.

Start only after R2, R10 and H2 are merged. Owns: `src/SA.ReactionControl/Controller/*`, `tests/SA.ReactionControl.Tests/Controller/*`, `docs/port/R9.md`. Edit nothing else.

## Deliver

`Controller/ReactionController.cs` with one entry point:

```text
static ControllerReport Tick(in ControllerProfile profile, ref ControllerState state, ReadOnlySpan<RoleBody> bodies, ReadOnlySpan<SupportProbe> feet, ReadOnlySpan<SupportProbe> forwardProbes, in ControllerInput input, Span<JointDrive> drives)
```

It runs, in a fixed documented order: coordination (`Coordinator.Arbitrate`) to choose the owning mode, then the owner's controller (`BalanceController.Tick` while balancing, `BodyBalance.Tick` and `CatchFall.Tick` while falling, `Brace.Tick` while bracing, `GetUp` selection while recovering), then `BlendWeights` to fade between owners, then `Drive` limits and soft limits, writing every role's `JointDrive`. `ControllerState` holds the state of every sub-controller. `ControllerReport` names the owning mode and why.

## Check, using the harness scenarios from H2

Record measured numbers in `docs/handoff/R9.md`.

1. A table of outcomes: push magnitude (60, 120, 200, 300, 450 N·s) by eight directions: recovered standing, recovered after steps, or fell. Expect a monotonic story: small pushes recover, large ones fall; report where the boundary is.
2. Exactly one mode owns the controller each tick; modes never flicker faster than the hysteresis allows.
3. Falling forward with a wall probe in reach selects `Bracing` and the report says so. With nothing in reach it selects the safe-miss pose.
4. After a fall the controller reports `Recovering` and asks `GetUp` for a clip; with no clip supplied the report says "no suitable clip" and the character stays passive.
5. Determinism, hostile inputs give passive drives, no allocation per tick.

Tuning is expected. Put every change in `docs/tuning.md` under "Tuning log" (R10 owns the file layout; append only your rows) and keep it honest: report scenarios that still fail.
