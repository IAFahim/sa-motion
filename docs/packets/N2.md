## API (exact names)

```text
struct Frame { Float3 Position; Quaternion Rotation; static Frame Identity }
enum Axis : byte { X, Y, Z }
struct Float3x3 { Float3 C0, C1, C2; static Identity; Float3 Multiply(Float3 v); Float3x3 Transpose() }
static class Frames {
  Frame Compose(Frame outer, Frame inner)      outer * inner
  Frame Inverse(Frame frame)
  Frame Relative(Frame parent, Frame child)    Inverse(parent) * child
  Float3 TransformPoint(Frame frame, Float3 point)
  Float3 TransformDirection(Frame frame, Float3 direction)
  Frame Mirror(Frame frame, Axis normal)       reflect across the plane whose normal is the axis
}
static class Inertia {
  Float3x3 ToWorld(Float3 principal, Quaternion orientation)         R * diag(principal) * R^T
  Float3x3 InverseToWorld(Float3 principal, Quaternion orientation)  principal component <= 1e-6 gives inverse 0 (axis locked)
}
```

Totality: a rotation that is not finite or has near-zero length is treated as identity. A non-finite position is treated as zero. Never throw.

## Tests

- `Compose(Inverse(f), f)` is identity and `Relative(parent, Compose(parent, local))` equals `local`, over 200 random non-identity frames, within 1e-5. Quaternions compared up to sign.
- Composition is associative on random frames.
- `TransformPoint(Compose(a, b), p)` equals `TransformPoint(a, TransformPoint(b, p))`.
- Mirror property for all three axes: `TransformPoint(Mirror(f, axis), mirror(p))` equals `mirror(TransformPoint(f, p))`, where `mirror` negates that axis component. Mirroring twice returns the frame.
- Inertia: `ToWorld` is symmetric, its trace equals the principal trace for any orientation, `ToWorld * InverseToWorld` is identity for positive principals, and a zero principal component gives a zero inverse on that axis.
- Degenerate inputs return defined values: NaN frames, zero quaternion, negative principals.
