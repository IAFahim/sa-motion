## Deliver

`GetUp/*`: classify the resting pose (supine, prone, side, upright, unknown) from `ReadOnlySpan<RoleBody>`; choose which get-up request to make from a list the caller provides (clip ids with start-pose metadata: required orientation class and root offset); compute the root alignment target (position and facing) for starting the clip; a clearance check over caller-supplied probes. There are no game animations in this project, so return an explicit "no suitable clip" result rather than inventing one.

## Check

- Bodies laid supine, prone and on the side are classified correctly, including 180 degree yaw variants.
- Choosing among clips picks the one whose start-pose class matches; with none, the result is "no suitable clip".
- Root alignment faces the direction of the pelvis forward projected onto the ground; the target is finite and within stated bounds.
- Blocked clearance returns "blocked", not a get-up.
